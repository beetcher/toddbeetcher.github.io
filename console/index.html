Welcome aboard the bridge

This is the LAUNCH Console: the control room for the I Can Do That workshops. It is a fun first surface, built to learn on. The production console will look different; the lists, forms and ship's rules carry over.

Flight basics

  1. Pick a station. The menu at the top of every screen jumps to any station. The tiles below do the same.
  2. Each station is a list. Tap a card to open it. Use Add and Edit to change things.
  3. The ship protects its records. If something is refused, the message names the field and says why. Nothing is half-saved.
  4. Back to the bridge any time: tap the LAUNCH tile in the top left.
  5. Lost? Open the ship's manual below, or tap Manual on any station.
