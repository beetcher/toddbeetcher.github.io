# Black Flag Ventures discussion sketch

A 12-panel enterprise-facing explanation of the Black Flag manufacturing and venture-creation thesis. Narrative source: the supplied October 22, 2026 discussion paper. This remains review material; enterprise performance, commercial terms, governance, and the capital bridge require validation.

## Preview

From the repository root, run a local static server and open `/bfv/`. For example:

```sh
python3 -m http.server 8874 --bind 127.0.0.1
```

Then visit http://127.0.0.1:8874/bfv/.

There are no build dependencies, external fonts, analytics, submission forms, or remote image dependencies. Paths are relative so the page works under `/bfv/`.

## Contents

- `index.html`, `style.css`, `main.js`: story, navigation, and image dialogs.
- `assets/`: five unchanged supplied illustrations.
- `paper.html` and `paper.txt`: full supplied paper.
- `discussion.html`: proposed discussion worksheet; nothing is sent or collected.
- `parking-lot.html`: review requests and decisions.
- `docs/`: storyboard, source provenance, parking lot, and verification record from the original sketch.

## Status and distribution

Prepared for review; no production engagement or investment program is implied. The “private discussion” label and noindex metadata express intended use; they do not provide access control. If committed to a public repository, these files are publicly readable. GitHub Pages serving this directory would also expose review notes and the paper.
