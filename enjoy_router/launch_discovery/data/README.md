# Shared ZIP table

`us_zips.json` (built by `enjoy_router/build_zip_table.py`): ZIP -> [state, latitude, longitude, place name] for the 50 states and DC.

Source: GeoNames postal code data, https://www.geonames.org/postal-codes/ , licensed Creative Commons Attribution 4.0
(https://creativecommons.org/licenses/by/4.0/). Credit: "ZIP code data from GeoNames". The file is not present until the build script
has been run once on a computer with internet access.
